# World Clock Card

A clean and customizable world clock card for Home Assistant.

Show the local time as a **digital** or **analog** clock, add up to **two extra
time zones**, and style every part of it — all from the UI editor.

## Features

- 🕐 Digital & analog clock faces
- 🔀 Two layouts — local time centered, or split with zones on the side
- 🎯 Dial styles — ticks, dots, numbers, roman numerals or numbers-in-circles
- 🌍 Up to 2 world clocks, each with its own label, dial and color
- 📅 Localized date in six formats
- 📐 Four sizes that scale everything proportionally
- 🎨 Colors for dial, digits and date, with auto-contrast on dark dials
- 🖼️ Transparent, image + overlay, or CSS gradient backgrounds
- 🛠️ card-mod friendly (CSS variables for every element)
- ⚙️ Fully configurable from the visual editor

See the [README](https://github.com/korova-sq/world-clock-card) for the full
list of options, examples and card-mod recipes.
